# TradeLens Frontend

React + TypeScript + Vite frontend starter for the trading analytics dashboard.

## Included
- React Router
- TanStack Query
- Axios API client
- Tailwind CSS
- Zustand UI store
- Lightweight Charts starter component
- Pages for dashboard, trades, analytics, and trade detail

## Quick start
```bash
npm install
cp .env.example .env
npm run dev
```
